# Hi, I’m Qiyang Hong

I build transferable AI and machine-learning methods for biomedical and scientific problems. My current interests include clinical LLM evaluation, research agents, population-scale phenotyping, and tools that make scientific work easier to inspect and reproduce.

I care about a simple standard: an AI system should make the work more useful without blurring the evidence behind it.

## Featured open-source work

### [De-AI Writing](https://github.com/qiyanghong2020/de-ai-writing)

An MIT-licensed Agent Skill for Chinese and English academic, medical, professional, and long-form writing. It protects claims, numbers, citations, uncertainty, and author register while editing. For longer conceptual manuscripts, it can also audit thesis recurrence across sections, concept relabeling, decorative taxonomies, and contribution-to-length imbalance.

The skill works with Codex, Claude Code, and Cursor. Its repository includes worked synthetic examples, deterministic contract tests, and a 12-case evaluation specification. Those checks define expected behavior; they are not evidence that every model or Agent will produce a correct rewrite.

### [ukbFound](https://github.com/qiyanghong2020/ukbFound)

A public codebase for representing UK Biobank phenotypes as language-like sequences and studying disease stratification, disease relationships, and risk prediction. Controlled UK Biobank data and derived artifacts are excluded from the repository.

## Research direction

I am interested in methods that transfer across biomedical questions rather than treating AI as a one-off analysis step. That includes model development, evaluation, longitudinal and multimodal health data, LLM and Agent behavior, and scientific workflows with explicit evidence boundaries.
